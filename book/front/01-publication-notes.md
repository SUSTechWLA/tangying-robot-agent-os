# 出版说明与阅读约定

## 本版范围

《深入理解分布式机器人 Agent 系统》数字版 **3.3.0，2026-11-02**，副标题“从自动会话到长程执行：上下文、成本与持久恢复”。全书四篇、19 章、9 附录，含 25 幅离线 SVG 与 2 幅教学插画。新增自动接收会话、模型成本分层两图，将近期系统升级纳入正文与课程资料。

实现核对固定到 `27cbbbaf96e2d76e1a17a1ea1befc8a8d8db14ce`；配套项目文档另由 `book/edition.json` 的 `documentation_snapshot` 固定。出版器将书稿、图形、生成器与依赖的 SHA-256 写入 provenance.json，代码身份不会随排版变化。本次是文档与出版同步，没有修改机器人运行时代码、部署当前进程或新增运动实验。

重点增量：Local 自动 session/turn、预分配 task 与 pending 查账；原句/历史 reference 分离及长原文回查；真实 usage、recipe 和 KV cache 的成本边界；Nav2 新鲜依赖与故障部分地图；工作台巡检失败、受控介入及后续独立仿真成功。它们的研究证据各自保留原提交，不能统一改标成本版实验。

## 阅读中的四种材料

“教学设定”“算例”“伪代码”用于推导，不代表实测或可直接发送的请求；“当前项目”指本版固定实现；“实际实验”指原报告记录；“建议”“后续扩展”表示未实现或未验证。模型、软件 fixture、Gazebo 与实机是不同的测量层级。

当前会话服务本地单操作员，未建立多用户隔离、跨渠道 Router 或任务创建 HTTP 重发去重；会话恢复在下次同分区 Begin 查账，不自动重放动作。历史、摘要、KV 命中与物理权限是独立对象。示意图中的逻辑框不自动代表独立进程或原子跨域事务。
