# 数字版 3.0.0 · 架构推导与故障实验版

日期：2026-10-21。代码及配套项目文档复核提交：`9e6a58f6ad48c6d9441e95511ddb4d503ea6449e`。书籍版号独立于软件版本。

本版重写全部 19 章，将组织方式从“功能、边界和报告清单”改为“问题 → 架构选择 → 数据流 → 故障反例 → 实现 → 取舍”。以巡检任务贯穿全文，集中讲清执行权威、物理完成、恢复与上下文，历史原始身份集中到附录和原报告。

具体变化：

- 16 幅本地 SVG：架构、工具链、任务时序、恢复分支、地图数据、工作台作用域、云边合同、同行数据和上下文投影；HTML 与 EPUB 均内嵌或携带图表。
- 两个仅用 Python 标准库的小实验，分别演示丢响应导致重复效果、盲截断导致约束丢失。明确教学夹具与生产机制的差别。
- 19 章保留 57 道分层题，增加具体数值演算、失败窗口、替代方案和源码阅读问题；14 组项目实验、16 周课程，以及两份课堂时间分配与讨论脚本。
- 更新到共享 Edge Host、目标委托、空间探索/覆盖、agent.data.v1、robot 工作台隔离等实现；区分 Host 进度摘要与 actionloop managed view 两条上下文路径。
- 第 19 章分析原始失败和后续新任务，解释开发者修复、自动恢复与结果核验各自发生在哪里。
- 发布器加入本地被动 SVG 校验、哈希追溯与离线打包；旧 2.2.0 源身份和生成器可通过档案恢复。

核验记录见 `docs/development/2026-10-21-book-teaching-redesign.md`。本版新增的是教材、出版验证和软件课堂实验；没有新增机器人运动或实机验收。正式发布内容身份以产物 `provenance.json` 和 `SHA256SUMS` 为准。
