我写了个分布式机器人 AgentOS


我一直有个执念：机器人不该是需要"学"才会用的东西。

它应该像家里的人：你说一句，它去做；被打断了，接着做；换了一台，记忆还在。

所以我写了个分布式 AgentOS："大脑"能装在机器人身上离线跑，也能接云端调度多台（多机在仓库里，当前主线是先让一台机器人把活干完）。它面对的不是某一种机器人，而是各种本体——机器人换了，任务、工具、证据链不用重写。

① 拿到机器人，第一句话就能用

不用写代码、不用学 App，更不用碰坐标和关节角。控制台里说一句"去厨房拿杯子，放进收纳盘，再回客厅"，它自己拆成十几步，把计划摊开给你看，你点头它才动。每一步都用动作之后新拍的画面确认，而不是相信一句"我做完了"。

② 它随时可以被打断，也随时能接着做

这是我花最多力气的地方。任务能暂停、能继续；需求变了是"改版"而不是从头再来；断电重启，它回到原来的地图和任务账本；扫过的地图可以继续往外扩，不用重扫。

最要紧的是：恢复时它会重新核对历史，而不是盲目重放动作——不会为了"续上"多抓一次、多走一趟。失败也分得清：能恢复的就带着原因退到安全姿态，而不是卡死。

③ 它做的每件事都留证，包括失败

一句话进来被拆成十几步：哪一步用了哪次采集、耗时多久、图的哈希，全都能回放。做机器人最怕"看起来是对的"，所以我让它每次都留下能被翻旧账的东西。

④ 我想要的画面

家里的机器人第一次开机就知道自己在哪、该干什么；你出差在外，让它自己把屋子巡视一圈，回来给你一份"一切正常"；老人不用学界面，说一句"把药拿过来"就行；机器人换新硬件，任务和记忆接着用，像换了手机但数据都在。

我希望有一天，机器人不是在展台上跳舞，而是在你家里真的把活干完。我现在做的，就是让这件事在软件上先成立。

⑤ 它已经有完整的文档

装机、标定、建图、接实机、发版，文档按"你想做什么"组织，九十多篇。想自己跑一遍：仿真不需要显卡，演示默认走确定性解析、不配 API Key 也能跑通；开发时想让系统听懂更多说法，才需要自己配一个 LLM Key。

最后说句正事：我在找具身智能 / 机器人软件相关的工作（机器人 Agent 与系统、SLAM 方向）。这些不是 PPT，是能跑、能复现、有文档、有失败复盘的工程。缺一个愿意从像素抠到系统的人的话，求内推、求聊聊 🙏

这条路我走了很久，会一直走下去。🤖
