# 第 01 期：总体架构

"从零到一入门机器人开发"系列的**第 1 期**，也是整个系列的入口。面向想入门机器人开发、但不知道从哪下手的人。

## 本期要回答的问题

这套系统到底是什么？一句话任务怎么变成十几步动作，每一步又怎么留下能回放的证据？

一句话答案：**它不是遥控台，是一套分布式的机器人 AgentOS**——把一个大脑装进机器人（离线形态），或者接上云端调度多台（扩展路线），两种形态共用同一套 Runtime、工具、观测与世界契约。

## 口径边界

- 本期只讲**总体架构**，不深入任何单点（单点留给后续各期）。
- 主线是**一台机器人**在受限环境把活干完；云端多机是仓库里已经实现的**扩展路线**。
- 数据图由运行日志与地图产物重绘，**不是界面截图**——两类素材别混用。
