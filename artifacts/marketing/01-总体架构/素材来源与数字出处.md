## 1. 界面截图是怎么来的（`_assets/screens/`）

十一张都是**页面自己渲染出来的画面**，不是拼图、不是示意图。分两类：

**(a) 本机控制台**（`http://127.0.0.1:8897`，`bash scripts/furnished-home-demo.sh start` 起的服务）：

- 方式：无头 Chromium 通过 DevTools Protocol 打开页面，用页面**自己的控件**切换（侧栏 `工作台 / 任务记录 / SLAM 建图 / 我的机器人`），点关键帧列表里的行打开弹窗，点任务行后切到工作台渲染"任务全过程回放"；
- 每一张都**先断言面板已加载完**再截：SLAM 面板看 `#saved-keyframes-summary` 文本、列表行数、画布尺寸；弹窗看 `dialog.open`、图片数、字段数、配准记录数；回放面板看 `#local-replay-body` 子节点数与状态文案（"已按事件顺序对齐工具调用、观测证据与恢复状态。"），因此不会出现半加载的画面；
- 视口 1440×1080、设备像素比 2 → 输出 2880×2160（4:3）。

**(b) 公开仓库页面**（GitHub 渲染，无需登录）：

- `07-仓库首页.png`：仓库首页，含 Public 标识、About 里的项目定位、代码目录、语言构成、Release；
- `08-文档索引.png`：`docs/README.md` 的渲染结果，左侧是整棵文档树（92 篇 markdown），正文是"按任务阅读"索引表；
- `10-系统架构文档.png`：`docs/production/architecture.md` 的渲染结果（完整系统架构、目标与创新点、两种部署形态）——长文系列第 01 期的头图；
- `11-分布式形态文档.png`：`docs/distributed-agentos.md` 的渲染结果（云端 Fleet 与离线 Local Brain 的两条边界、持久化与单写范围、仍须独立验证的范围）。

两份文案（`小红书文案.md`、`小红书长文-01-总体架构.md`）都是**纯文本、可直接整段复制**：没有 markdown 符号（粘到小红书不会出现 `**` 或 `###`），第一行是标题（控制在 20 字内），其余是正文加话题标签。短文正文连链接与话题 997 字（上限 1000），长文正文约 3200 字（发"长文"）。

**长文系列**（`小红书长文-01-总体架构.md`）里"八层模块"的说法逐条对应 `docs/production/architecture.md` 的 §3 模块职责与 §4 权威数据流；"第一次打开仓库按什么顺序读"来自 `docs/README.md` 与仓库实际目录。后续各期请沿用同一份架构文档：**架构改了要同步改文档，别只改文案**。

## 3. 文案里的能力说法对照（分布式 / 恢复 / 开箱即用）

| 文案里的说法 | 实际依据 |
| --- | --- |
| "一个大脑可以装在机器人身上离线跑，也可以接云端调度多台" | `docs/distributed-agentos.md`：联网主形态是云端 Fleet，离线形态是独立 Local Brain，两者共享同一套 Runtime / 工具 / 观测 / 世界契约 |
| "机器人换了，任务与工具不用重写" | README「真机（Sim2Real）」：同一套任务、工具与证据合同在实机上不变，替换的是适配器、感知、标定与现场安全配置 |
| "不用碰坐标和关节角" | README：模型不接触关节角、轮速或坐标；工具都是 LLM 可 function calling 的 |
| "把计划摊开给你看，你点头它才动" | 控制台批准流程（`批准物理动作`）与任务审批字段 |
| "每一步都用动作之后新拍的画面确认" | 闭环契约 `core/closedloop`：`mutates_world=True` 的工具返回成功只触发观察，缺新鲜证据即该步未完成 |
| "任务能暂停、能继续" | `core/taskgraph/state.go` 的 `PAUSED` + 本地应用暂停转移；控制台「安全暂停 / 继续任务」 |
| "需求变了是改版，不是从头再来" | `tasks/service.go` 的 `CurrentRevision` / `RevisionState`（修订提案与批准） |
| "断电重启回到原来的地图和任务账本" | 地图：`active-map.json` 与激活时恢复；账本：Local 使用 SQLite（`docs/distributed-agentos.md`） |
| "已经扫过的地图可以继续往外扩" | 续建：`mapping.start { mode: "explore", baseMapId }` 继承坐标系、点云与栅格 |
| "恢复时重新核对历史，不盲目重放动作" | `tasks/local_recovery.go`：Local App 每次 resume 重新核对持久历史；回放面板读取 `canResume` / `requiresReconciliation` |
| "能恢复的失败退到安全姿态" | `RECOVERABLE_FAILURE` + `recover_to_safe_pose` 工具 |
| "一句话被拆成十几步，每步绑一次采集并留哈希" | `_assets/screens/09` 就是真实面板：12 个工具步骤、12 次确认、13 份采集，逐步显示耗时、相对命令时间、来源与 SHA-256 |
| "文档按你想做什么组织" | `docs/README.md`「按任务阅读」索引；仓库共 92 篇 markdown |
| "仿真不需要显卡、不需要 API Key" | README：不需要 LLM API Key，也不需要 Docker；本机为纯 CPU 环境实测可跑 |
