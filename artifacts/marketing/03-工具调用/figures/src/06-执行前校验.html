命令发出之前，要过九道闸门

物理动作的代价不可撤销，所以尽量把错误挡在执行之前。下面这些校验全部发生在机器人开始动之前。

最高级（安全相关的动作）必须同时具备三样东西：副作用标记、默认租约、允许的安全 profile。缺任何一样，工具加载时就报错——不给它运行的机会。

外部入口也守同样的规矩
外部 Agent 通过 MCP 接入 MCP

只提供 8 个粗粒度工具：列出机器人、查能力、看世界快照、建任务、查任务、取消任务、急停等。不提供批准、不提供自动批准、不提供重置急停，也不暴露关节控制。外部 Agent 建的任务一样要人工审批。

给模型的是任务级工具 任务级

关节角级和位姿级的两个原始接口（move_arm_to_joints、navigate_to_pose）根本不暴露给大模型，只留给工程调试。给模型的是 pick_object、place_object、navigate_to 这种带语义的任务级工具——模型不接触关节角、轮速和坐标。

为什么前置校验这么重要 软件调用出错，回滚的代价是毫秒级；物理动作出错，代价是不可撤销的。所以物理系统的设计取向是把错误挡在动作之前，而不是指望出错之后能救回来。
