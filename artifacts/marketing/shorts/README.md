# 短文连载（每天一更）

长文（3000–5500 字）数据不好，改成短文：**一条一个点，350–550 字，能直接整段复制粘贴**。

- 选题、排期、论文映射、发布纪律：见上一级 [讲什么-短文连载计划.md](../讲什么-短文连载计划.md)
- 每条的规格：第一行标题（≤20 字）→ 正文（**300–450 字**，纯文本、无 markdown 符号）→ 仓库链接 → 4–6 个标签
- **语气：讲人话**。开头用生活场景，术语先翻译再出现，数字最多一个。去术语对照表见[计划](../讲什么-短文连载计划.md)第一节
- 求职诉求只在**置顶那条**（S05）与每周一条里出现，其余不带
