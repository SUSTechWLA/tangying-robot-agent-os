# 短文连载（每天一更）

长文（3000–5500 字）数据不好，改成短文：**一条一个点，正文 260–450 字，整段复制粘贴就能发**。

- 选题、排期、论文映射、发布纪律：见上一级 [讲什么-短文连载计划.md](../讲什么-短文连载计划.md)
- 话题与全平台状态：[00-选题与索引.md](../00-选题与索引.md)

## 发布格式（照抄，不要改结构）

```
深入理解分布式机器人AgentOS（一）        ← 总标题 + 期号（正文第一行，20 字）
机器人说"我做完了"，你信吗                ← 本期钩子（正文第二行，填进标题栏，≤20 字）

正文 260–450 字，一段一个意思，纯文本无 markdown 符号。

项目开源在 GitHub：github.com/SUSTechWLA/tangying-robot-agent-os
一句话：你说人话，它自己拆任务、走过去、动手干完，每一步都留证据；README 里有跑起来的步骤。
连载中，下一篇：<下一期钩子>。觉得有点用的话，点个 star 就是最大的支持。

#开源项目 #机器人 #具身智能 #AI #家庭机器人
```

**为什么标题放正文里**：发布时整段复制即可，不用在标题栏和正文之间来回搬。
第一行是**系列标识**（每期只差一个字），第二行是**本期标题**；标题栏建议填第二行（钩子更像"点进来"的理由），
第一行留在正文里做连载识别。行动区三行固定不变，只换下一篇预告——**项目宣传靠固定结构重复出现，不靠每条现编**。

**字数口径**：正文 260–450 字（越短越好，超过 500 就该拆成两条）；全文含行动区与标签 450–650 字，离平台 1000 字上限有余量。
