# 宣传材料

对外发布物的唯一入口。**这里没有任何构建、测试或运行时读取**——`artifacts/marketing/` 下的文件只被人读，改错了不影响产品。

内容按**系列（一期一个主题）**组织，每期自带小红书稿、平台适配稿、配图与出处。所有能力说法必须先过各期的 `素材来源与数字出处.md` 才能发。

## 三个平台，三种写法（别直接复制粘贴）

同一期的内容在不同平台要改写，不是搬运：

| 平台 | 形态 | 关键差异 |
| --- | --- | --- |
| **小红书** | **短文**：正文 ≤1000 字<br>**长文**：约 3000–5500 字 | 两种都是**纯文本**：不能出现 markdown 符号；第一行是标题（≤20 字）；短句、留白、话题标签。短文是硬限制，长文是"发长文"形态 |
| **知乎 / 公众号** | 技术长文 | 可以用标题层级、代码块、表格；先给结论再给论证；篇幅不设上限 |
| **B 站** | 口播稿 | 前 3 秒钩子；按镜头分节；写"说出来的话"而不是"读起来顺的句子" |

小红书正文是**纯文本**：粘过去不能出现 `**`、`###`、反引号。平台适配稿（知乎版、口播稿）可以正常用 markdown。

文件名约定：小红书两份带期号（`小红书长文-NN-主题.md`、`小红书短文-NN-主题.md`，方便跨期归档时一眼看出属于哪期）；其余平台用固定名（`知乎-公众号.md`、`B站口播稿.md`）。

## 配图怎么用

- **每期自己画的图**放本期 `figures/`，用 `tools/` 的渲染管线生成。
- **跨期复用的截图与仿真渲染**放 `_assets/`，不要每期复制一份。
- 图片是**产物**：改文案改 `figures/src/*.html`，再重跑脚本，不要手改 PNG。

```bash
cd artifacts/marketing
PLAYWRIGHT_MODULE=<playwright-core 路径> node tools/render.mjs              # 渲染全部期
PLAYWRIGHT_MODULE=<playwright-core 路径> node tools/render.mjs 03-工具调用    # 只渲染第 03 期
PLAYWRIGHT_MODULE=<playwright-core 路径> node tools/render.mjs 03-工具调用 04 # 只渲染其中一张
```

脚本会自动在本机 playwright 缓存里找可用 Chromium，也可以用 `CHROME_PATH` 指定。详见 [`tools/README.md`](tools/README.md)。

## 新建一期怎么做

1. 复制 `_模板/` 为 `NN-主题/`（NN 与系列期号一致）。
2. 先写 `素材来源与数字出处.md` 的骨架——**先定"哪句话有依据"，再写正文**，能省掉大量返工。
3. 写 `小红书长文.md`（它是口径基准），再从中派生短文、知乎版、口播稿。
4. 画图：复制 `figures/src/example.html`，改文案，跑渲染脚本。
5. 把这一期加进 `00-选题与索引.md` 的表格。

## 口径纪律（每一期都适用，违反会出事）

1. **每句能力说法都要指得出实现或测试**；指不出来就删掉，或明写"尚未验证"。
2. **架构或行为改了，同步改文档与文案**，不要只改文案。
3. **主线与扩展路线分开说**：当前主线是一台机器人在受限环境把活干完；云端 Fleet 是仓库里已经实现的扩展路线，不等于"单机开发栈已具备跨地域生产级高可用"。
4. **恢复能力按实际范围写**：单主进程重启范围内的部分状态恢复；跨主机共识、跨存储事务、数据库/队列切主仍在"仍须独立验证"。
5. 发布前逐条过该期 `素材来源与数字出处.md`。历史上两份出处表各记了一次真实修正：
   - 第 02 期："断网后边缘继续跑" → 实际口径是**断网停止**（依据 `docs/production/operations-and-failures.md`）；
   - 第 03 期：为一句文案**补了一个原本缺失的测试**（`core/skills/manifest_test.go`）。
6. 涉及协议/授权的说法要跟仓库根 `LICENSE` 一致（当前 **MIT**，2026 年由 Apache-2.0 改来）。

## 素材性质别混用

| 来源 | 是什么 | 规矩 |
| --- | --- | --- |
| `_assets/screens/` | **真实界面截图**（无头 Chromium 经 CDP 抓的本机控制台与公开仓库页面） | 只截"面板已加载完"的状态；不用重绘图冒充截图 |
| `_assets/renders/` | 仿真渲染 | 单独标注，不当作产品截图 |
| `各期/figures/` | **信息图 / 数据图**（手写 HTML+SVG 渲染，或由真实数据重绘） | 是产物，改源文件后重跑脚本 |
