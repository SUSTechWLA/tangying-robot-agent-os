## 正文

我一直有个执念：**机器人不该是需要"学"才会用的东西。**
它应该像家里的一个人——你说一句，它去做；被打断了，回来接着做；换了一台，记忆还在。

所以我写了一个**分布式 AgentOS**：一个"大脑"可以装在机器人身上离线跑，也可以接云端一起调度多台（多机那部分在仓库里，但我现在的主线是让一台机器人把活干完）；它面对的不是某一种机器人，而是各种各样的本体。机器人换了，任务、工具、证据那一套不用重写。

**① 拿到机器人，第一句话就能用**
不用写代码、不用学 App，更不用碰坐标和关节角。在网页控制台里说"从客厅出发，去厨房拿杯子，放进收纳盘，然后回到客厅"，它自己拆成十几步、把计划摊开给你看，你点头，它才动。每一步都用**动作之后新拍的画面**确认，而不是相信一句"我做完了"。

**② 它可以随时被打断，也可以随时接着做**
这是我花最多力气的地方。任务能暂停、能继续；需求变了，是"改版"而不是从头再来；断电重启，它回到自己原来的地图和任务账本；已经扫过的地图可以继续往外扩，不用推倒重扫。
最要紧的是：**恢复的时候它会重新核对历史，而不是盲目重放动作**——不会为了"续上"而多抓一次、多走一趟。失败也分得清楚：能恢复的失败就带着原因退到一个安全姿态，而不是卡死在那里。

**③ 它做的每件事都留证，包括失败**
一句话进来被拆成十几步：哪一步用了哪次采集、耗时多久、图与深度的哈希，全都能回放。做机器人最怕"看起来是对的"，所以我让它每次留下可以被翻旧账的东西。

**④ 想要的画面**
我想象过很多次：家里的机器人第一次开机就知道自己在哪、该干什么；你在外地出差，让它自己把屋子巡视一圈，回来给你一份"一切正常"；老人不用学任何界面，说一句"把药拿过来"就行；机器人老化换新硬件，任务和记忆接着用，像换了手机但数据都在。
我希望有一天，机器人不是在展台上跳舞，而是在你家里真的把活干完。**我现在做的，就是让这件事在软件上先成立。**

**⑤ 它已经有完整的文档**
不是一个 demo 仓库：装机、标定、建图、接实机、发版，文档按"你想做什么"组织，共九十多篇。想自己跑一遍，仿真场景不需要显卡，也不需要 API Key。

最后说一句正事：**我在找具身智能 / 机器人软件相关的工作**（机器人 Agent 与系统、SLAM 与导航方向）。上面这些不是 PPT，是能跑、能复现、有文档、有失败复盘的工程。如果你们在做机器人、缺一个愿意从像素抠到系统的人，**求内推、求聊聊** 🙏
这条路我走了很久，还会一直走下去。🤖

## 发布小贴士

- 首图用仓库首页那张，第二张放界面——"真做了东西 + 真能用"两秒说完。
- 这条笔记的重点是**分布式 + 随时恢复 + 开箱即用**，数字只在被问到时报（毫米级误差、覆盖率那些），正文里不放，读起来才像在讲一件想做的事。
- 评论区第一条自己占：仓库地址 + 联系方式；如果有人问"能不能跑"，直接给 `make setup` + `make home-furnished` 两行命令。
- 有人质疑"云端和本地能不能自动切换"，诚实答：**现在是"显式交接"，不是自动故障切换**——这条写在文档里，专业度比吹牛值钱。
