# 第 03 期：软件 MCP 与物理世界工具调用

"从零到一入门机器人开发"系列第 3 期的宣传物料。这一期回答一个被问得最多的问题：

> 你们的 MCP、这些工具，和 Codex、Claude 调 GitHub API 有什么区别？不都是工具调用吗？

一句话答案：**协议上没有区别，语义上几乎是相反的。MCP 把"怎么调用"标准化了，但"调用之后世界变成什么样"它管不着。**

上一期（为什么要分布式）在 `../series-02-distributed/`，第 1 期（总体架构）在 `../小红书长文-01-总体架构.md`。

## 本期要回答的四个问题

1. 软件工具调用和物理世界工具调用，本质区别在哪？
2. 为什么"工具返回成功"不能算完成？
3. 结果未知为什么不能自动重试？
4. 我们具体做了哪些处理和优化？

## 核心数据（来自仓库根目录 `tools.json`）

| 说法 | 数值 |
| --- | --- |
| 工具总数 | 30 |
| `mutates_world = true` | 14 |
| `idempotent = false` | 14 |
| 幂等且不改世界（可安全重试） | 15 |
| 不暴露给大模型 | 2（`move_arm_to_joints`、`navigate_to_pose`） |
| MCP 对外工具 | 8 |

两个说明性极强的特例：`set_gripper_width` 既改世界又幂等；`reset_safety_stop` 不改世界但不幂等——证明"改不改世界"和"能不能重试"是两个正交维度。
