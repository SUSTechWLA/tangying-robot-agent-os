# _模板 · 新建一期时复制这个目录

```bash
cd artifacts/marketing
cp -r _模板 04-底盘会走路
```

然后按下面顺序写。**顺序很重要**——先定依据，再写正文，能省掉大量返工。

---

## 写作顺序（别跳步）

### 第 1 步：`素材来源与数字出处.md`

先把"这一期我要说哪几句能力话、每句的依据在哪"列出来。这一期如果挖不出足够的实现与测试，说明选题还不成熟，**这时候换题比写完再改便宜得多**。

### 第 2 步：`小红书长文.md`

它是**口径基准**（约 3000–5500 字）。后面所有形态都从它派生，所以先把它写对。写作要求：

- 第一行是标题，**≤ 20 字**，整篇纯文本；
- 不强求 markdown 符号（粘到小红书不会出现 `**` / `###`）；
- 结构：钩子 → 结论先行 → 分节论证 → 边界说明 → 下期预告 → 仓库地址 → 话题标签；
- **必写一节"边界"**：这一期讲的东西，做到哪一步、没做到哪一步。

### 第 3 步：`小红书短文.md`

从长文压缩到 **1000 字以内（含链接）**，保留结论与最有画面感的例子，砍掉论证过程。

> 教训：第 02、03 期的短文都压到**正好 1000 字**，反复削了三五轮才达标。建议按 **950 字**起草，留余量。
> 计数口径：去掉话题标签与分隔线，`github.com` 链接**算**在正文里。命令见本目录末。

### 第 4 步：`知乎-公众号.md`

同一内容的长文形态，**结构不同**：可以用标题层级、代码块、表格；先给结论再给论证；篇幅不设上限。可以直接从长文扩写，补上小红书版为篇幅砍掉的代码细节。

### 第 5 步：`B站口播稿.md`

口播稿写的是**说出来的话**，不是读起来顺的句子。按镜头分节，每节标时长与画面对应。

### 第 6 步：画图

```bash
cp _模板/figures/src/example.html 04-底盘会走路/figures/src/01-xxx.html
# 改文案（图源在 figures/src/，用共享设计系统 tools/theme/theme.css）
cd artifacts/marketing
PLAYWRIGHT_MODULE=<playwright-core 路径> node tools/render.mjs 04-底盘会走路
```

### 第 7 步：登记

把这一期加进 `00-选题与索引.md` 的状态表与配图映射。

## 计数命令（发布前跑一次）

```bash
cd artifacts/marketing/04-底盘会走路
python3 -c "
import re, pathlib
p = pathlib.Path('小红书短文.md')
t = p.read_text(encoding='utf-8')
body = t.split('——————————————')[0].rstrip().split('\n')
title, rest = body[0], '\n'.join(body[1:]).strip()
n = len(re.sub(r'\s', '', rest))
print(f'标题 {len(title)} 字（上限 20）')
print(f'正文含链接 {n} 字（上限 1000） →', '✓' if n <= 1000 else f'✗ 超 {n-1000}')
"
```
