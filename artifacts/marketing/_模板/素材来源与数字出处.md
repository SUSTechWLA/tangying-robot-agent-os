## 0. 本期的三个边界（先写这一节）

写任何一期之前先把边界定下来，正文才不会写飘：

| 项 | 本期怎么说 |
| --- | --- |
| 当前主线 | 一台机器人在受限环境（装修家庭/固定工位）把活干完 |
| 扩展路线 | （哪些能力在仓库里已实现但不是主线，例如云端 Fleet 多机） |
| 仍须独立验证 | （逐条列出，不写"持续优化中"） |

> 通用口径（每一期都适用）：
> - 恢复能力限于**单主进程重启范围内的一部分状态恢复**；跨主机共识、跨存储事务、数据库/队列切主仍在"仍须独立验证"。
> - 仿真通过 ≠ 实机放行。断网停止、实体急停、限速、实际抓取成功率等属于现场验收项。
> - 协议/授权说法跟仓库根 `LICENSE` 一致（当前 **MIT**）。

## 1. 数字与计数（**照抄，不要凭印象**）

| 说法 | 数值 | 口径 / 复现命令 |
| --- | --- | --- |
| （例）工具总数 | 30 | `tools.json` 的 `metadata` 条目数 |

复现命令：

```bash
# 例：统计工具分类
python3 - <<'PY'
import json
d = json.load(open('tools.json'))
meta = d['metadata']
print('总数', len(meta))
print('改世界', sum(1 for m in meta.values() if m.get('mutates_world')))
print('非幂等', sum(1 for m in meta.values() if m.get('idempotent') is False))
PY
```

## 3. 图片是怎么来的

| 图 | 内容 | 性质 |
| --- | --- | --- |
| `figures/NN-xxx.png` | （一句话） | 信息图（手写 HTML + 内联 SVG）· 数据图 · 真实截图 |

- 每期自己画的图源在 `figures/src/*.html`，用 `tools/render.mjs` 渲染，2× 分辨率。
- 跨期复用的截图在 `_assets/screens/`（真实界面截图），仿真渲染在 `_assets/renders/`。
- **信息图是产物**：改文案改源 HTML 后重跑脚本，不要手改 PNG。
