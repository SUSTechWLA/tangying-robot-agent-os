# 素材来源与数字出处（发布前自查 / 被问到时的底稿）

## 1. 界面截图是怎么来的（`screens/`）

六张都是**控制台自己渲染出来的画面**，不是拼图、不是示意图：

- 目标：本机正在运行的控制台 `http://127.0.0.1:8897`（`bash scripts/furnished-home-demo.sh start` 起的本地服务）；
- 方式：无头 Chromium 通过 DevTools Protocol 打开页面，用页面**自己的控件**切换（侧栏 `工作台 / 任务记录 / SLAM 建图 / 我的机器人`），点关键帧列表里的行打开弹窗；
- 每一张都**先断言面板已加载完**再截：例如 SLAM 面板要看 `#saved-keyframes-summary` 的文本、关键帧列表行数、画布尺寸；弹窗要看 `dialog.open`、图片数、字段数与配准记录数，因此不会出现半加载的画面；
- 视口 1440×1080、设备像素比 2 → 输出 2880×2160（4:3）。

截图时抓到的面板状态（可复现）：

```
SLAM 建图面板：355 个关键帧 · 配准通过 343/865 · 未通过 522 次（主要：与参考子图重叠不足）· 4 个已接受回环
关键帧弹窗：#012 家庭地图 · kf-0011 · 只读采集证据
            图片 2 张（RGB 240×180 / 深度 240×180）· 字段 12 项 · 配准记录 2 条
            首条：#11 → #12 · 相邻帧 · 已接受 · RMSE 0.016 m · 内点率 60.6% · 对应点 815 · 修正 0.000 m
任务记录：45 行（其中验收四个任务均为「任务已完成」）
```

浏览器进程用完即退，没有改动任何地图或机器人状态。
