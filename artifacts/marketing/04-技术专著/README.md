## 与前三期的关系

前三期讲**系统的某一层**（总体架构 / 为什么要分布式 / 工具调用）。
这一期讲**一本把这些层全部讲透的书**，所以这是系列里唯一一期"宣传对象是文档而不是代码"的。

## 三件事与前 03 期不同

1. **书的每一句断言自带出处**，所以本期的出处表是分层的：书 → 章节 → 仓库文件。
2. **这一期刻意不配图**（原因见出处文件第 5 节）：宣传对象是书，最有效的"图"是目录与几个数字。
3. **这一期的"不能说的话"清单比前三期更长**，因为书写长了，容易被摘出一句话脱离边界。发布前请逐条过一遍出处文件第 4 节。
