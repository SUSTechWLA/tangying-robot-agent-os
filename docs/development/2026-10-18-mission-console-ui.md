# 机器人工作台视觉与交互更新（2026-10-18）

源码基线：`c178280d4182a4cf6562fa9458cb7d5b00d8a8c5`。本次变更的提交身份以该文件和前端文件的 Git 历史为准。延续[工作台 UX 规范](2026-09-27-console-ux-spec.md)中的任务、安全与回溯契约；历史审核结果不替代本轮验证。

## 目标与取舍

原工作台已经具备任务编排、现场观测、记录回放和开发诊断，但浅色管理界面的视觉层级较平均，任务输入与现场之间的主次关系不够鲜明。本轮采用克制的深色任务控制台：让非技术用户先理解“描述任务—核对计划—批准动作”，让开发人员通过原有开发模式进入诊断、遥测和证据。

科幻感集中在空间几何标识、现场窗口与青绿色交互重点。页面不增加虚构仪表、运行数据或模拟相机画面；大部分内容保持常规文字、清晰边界和可读间距。深色只是呈现方式，不代表系统已连接或机器人已就绪。

## 设计系统与布局

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 页面底色 | `#0b111b` | 导航、页面背景 |
| 内容表面 | `#121d2b` | 任务、记录与诊断分区 |
| 正文 | `#cbd9e6` | 连续阅读内容 |
| 交互重点 | `#65e0d3` | 主要操作、导航选中、焦点 |
| 待确认/警示 | `#efc17d` | 缺失条件与待处理提示 |
| 故障/危险 | `#ff9ca9` | 故障与停止、恢复相关提示 |

字体使用 `Avenir Next`、系统西文字体、`PingFang SC`、`Microsoft YaHei` 和通用无衬线回退，不依赖外部字体请求。标题、正文、辅助说明分层；任务编号等技术字段保留适合查阅的等宽呈现。状态同时保留文字，颜色不独立承担含义。

```text
桌面
┌─────────┬───────────────────────────────────┐
│ 导航    │ 页面标题 / 连接状态 / 准备摘要     │
│         ├────────────────────┬──────────────┤
│         │ 实际现场与观测     │ 任务输入     │
│         │                    │ 流程与控制   │
│ 开发模式├────────────────────┴──────────────┤
│         │ 当前任务进展、结果与证据          │
└─────────┴───────────────────────────────────┘

窄屏：标题与状态 → 准备摘要 → 任务输入 → 现场 → 进展
手机：底部文字导航；任务输入优先于现场
记录页：搜索与列表 → 选中任务回放；未选中时说明可查看的内容
```

## 实现与修复

| 文件 | 变化与原因 |
| --- | --- |
| [`web/styles.css`](../../web/styles.css) | 统一页面、表面、文字、边线、交互和状态色语义变量，替换原有浅色硬编码；Local 与 Fleet 共用同一套视觉语言。保留响应式断点、键盘焦点和减少动态效果偏好。 |
| [`web/index.html`](../../web/index.html) | 更新品牌几何标识与现场空态；任务流程改为有序步骤；任务记录未选中时增加用途说明。保留原控件 ID、导航入口和执行按钮。 |
| [`web/console_ui.js`](../../web/console_ui.js) | 修复“跳到主要内容”链接把 `#page-title` 作为路由处理、从当前页面退回工作台的问题。现在只聚焦并滚动到当前标题，保留页面、历史和已选任务。 |
| [`web/console_ui_test.mjs`](../../web/console_ui_test.mjs) | 增加跳转链接的路由、历史、任务上下文与焦点回归，以及常规 hash 导航和诊断展示边界回归。 |

现场空态的圆环和相机图形属于装饰，并明确显示“暂未收到现场画面”“当前现场状态未知”。它们不承载传感器测量，也不替代真实点云或相机帧。任务记录欢迎区只解释检索用途，选中任务后让位于真实回放。

视觉检查中还处理了以下细节：

- 相机区域同时设置最小高度和宽高比时，窄屏会被撑宽。明确约束 `width: 100%` 与 `min-width: 0`，390 px 页面恢复到 390 px 内容宽度。
- 保存地图的标记、视角切换、图例容器及证据弹窗改为深色表面；自由空间、未知区域的图例色块继续匹配原地图渲染颜色。
- 停止、恢复、问题筛选等按钮补齐悬停与禁用配色。危险提示保留语义颜色，主按钮使用深色文字保证对比度。

## 行为与安全边界

- Local 仍为“生成任务 → 核对步骤 → 批准物理动作”，显示任务流程不会提前审批或启动运动。
- Fleet 保留“创建并开始任务”的既有语义，以及开始后立即执行、先确认工作区域安全的提示；两种模式不被统一成含糊的“开始”按钮。
- 示例只填入任务草稿。页面导航、模式切换、历史检索和跳转主要内容不授权机器人动作。
- 准备检查、连接、新鲜度、故障和按钮准入继续由原数据及规则驱动；未知状态不能因主题或空态设计变成就绪。
- “安全暂停”仍会等待当前动作结束；现场危险仍应使用实体急停。开发模式是信息展示层次，不是权限边界。
- 本轮不新增后端 API、不改变规划器、控制器、物理停止或云边通讯协议，也不构成实机安全验收。
