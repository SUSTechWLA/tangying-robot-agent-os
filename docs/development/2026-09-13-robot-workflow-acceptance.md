# 注册机器人服务与完整工作流验收

日期：2026-09-13。基线：`e626893`。本轮在本机运行机器人服务和工作台，完成标定、实际移动建图、地图恢复与自然语言移动操作；没有连接实体机器人或调用外部在线语言模型。

## 交付行为

- Agent、任务规划和工作台通过注册服务访问机器人，不依据仿真或实机选择标定、地图或动作实现。语义地点与对象线索由机器人服务提供，绑定机器人、地图和标定版本。
- 工作台「整机标定 → 去处理」进入标定页。机器人算法和用户自行标定均可使用；用户可编辑参数、导入 JSON、保存算法说明，保存时验证版本并应用相机参数。
- 建图使用机器人受控移动期间采集的米制 RGB-D 与同帧底盘位姿，执行平面 ICP、回环和位姿图优化。导航栅格、彩色点云 LOD、轨迹、语义工作区与来源记录放入不可变地图包。
- 手动建图支持有限距离/角度、停止后继续和取消。保存地图自动加载到 SLAM 页；旧地图可查看、显式激活，并在标定及定位坐标系版本一致时恢复。
- 导航在已知自由空间中搜索，使用精确扫掠圆盘与障碍单元距离检查，优先沿通道中部行进。底盘保持当前朝向平移，到工作位后受控转向；机械臂回 HOME 后可通过预检的完整收臂路径再返航。
- 标定采用紧凑表格、折叠相机参数与固定保存入口。地图画布在无内容时隐藏，统计标签和值成组显示；恢复活动地图后自动加载 WebGL 点云。
