## 权威状态与一致性约定

- 中心管理任务意图、计划 revision、授权；边缘报告执行开始、回执、未知结果；物理成功仍由有效观测验证。
- 完整事件及 revision 记录是历史来源。阶段视图保留来源、命令身份和未知状态，禁止用最新任务 revision 补造旧事件身份。
- 历史压缩使用确定性外置，不让模型重新解释硬约束、未决动作或证据时间。保留原始 JSON、SHA256 和来源身份，模型按任务作用域回读。
- 预算覆盖上下文和最终模型请求。计量明确使用 UTF-8 字节的保守估算，不冒充供应商 tokenizer；输出和工具协议需留余量。关键状态放不下时停止并要求缩小阶段。
- 交接携带任务、机器人、revision、claim/command、计划摘要与证据基础；验证失败不得执行。持久接收后崩溃不能推断动作未发生。
- 断网不能保证即时获知中心取消。本轮采取执行前核验及持久检查点，不扩大离线物理权限。

## 测试矩阵

1. 超过 1000 条历史事件：早期约束、不同 revision/command 的 pending/unknown 保留。
2. 压缩：稳定哈希、输入不变异、完整 JSON 可还原、来源时间不刷新、硬状态超预算拒绝。
3. 回读：任务作用域隔离、哈希核验、未知 artifact 拒绝、分页边界不破坏 UTF-8。
4. 执行：过期/乱序/重复交接、并发接收、持久化失败、接收后或执行后重启；不得重复物理动作。
5. 模型输入：实际 HTTP 内容与决策日志一致；超限或上下文构造失败时不调用物理工具。
6. Go 全量及相关 race；部署 Python 契约回归；远程 CI。

## 已发现的基线问题

- `tasks.ContextFor` 仅保留末 64 条事件。
- `internal/actionloop` 将工具结果 JSON 直接截到 8192 字节；默认 legacy 路径不保留结构化输入快照。
- PR #21 基线 CI run `37338356490` 的 test/release-gate 失败源于部署测试的旧 calibration fallback 与 commissioning 计数器断言，生产契约已有独立测试。
