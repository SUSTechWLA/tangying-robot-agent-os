# 工作台 UX 升级规范（2026-09-27）

基线：`044afff48d3c683c24d433d3b49209a450c85ff3`。目标是减少操作路径和无效滚动，让操作者安排任务，让开发者从同一个任务编号追到命令与证据。保留历史规范和报告。

## 审核发现

| 原设计 | 影响 | 本轮约束 |
| --- | --- | --- |
| 准备检查默认完整展开 | 首屏被前置说明占用 | 收起细节，始终显示真实下一步 |
| 异常横幅展开大量恢复记录 | 任务输入被推到长页面底部 | 默认数量摘要，保留展开和问题处理入口 |
| 平板导航仅有图标 | 功能需靠猜测 | 图标与中文名称同时显示 |
| 历史任务打开后回到工作台 | 检索上下文与回放分离 | Local 历史同页回放，保留关键词 |
| 按编号查找和状态过滤，缺少内容搜索 | 需要先找到任务编号 | 在所有已读取记录中搜索内容/编号 |
| 数百条事件默认展开 | 结果、恢复与原始事件混在一起 | 保留完整事件，默认按需展开 |
| 问题筛选按钮继承白色文字 | 浅背景上文字难辨认 | 显式设置普通/选中前景色 |
| Gazebo 示例仍为退役桌面工位 | 与家庭场景能力不符 | 更新为已验收导航/巡检表达 |

## 设计计划

基础色板：导航深蓝 `#14283f`、画布灰蓝 `#eef2f6`、内容白 `#ffffff`、操作蓝 `#245ac7`、正文 `#24364b`、分隔 `#dce4ed`。状态使用绿 `#317568`、琥珀 `#8a6420`、红 `#bb3c4d`，同时附文字，不能只靠颜色判断。

中文字体采用 PingFang SC / Noto Sans CJK SC / Microsoft YaHei 的本机字体链，不加载外部字体。页面标题 24px，区块标题 17px，正文 14px，辅助信息 12px；任务编号与版本使用等宽字体和对齐数字。文本左对齐，任务输入突出，元数据收敛。

```text
桌面工作台                        桌面任务记录
导航 | 页面标题与连接状态         导航 | 搜索与证据状态
     | 问题摘要 / 使用准备             | 记录列表 | 所选任务回放
     | 实际现场 | 任务输入与控制        | 搜索过滤 | 结果与逐步证据
     | 当前任务步骤                    | 编号查找 | 原始事件（折叠）

手机/窄屏：文字导航 + 准备摘要 → 任务输入 → 现场 → 进展
历史记录：搜索 → 有界滚动列表 → 回放
```

设计复核：不增加展示型首页或统计装饰。深色只用于导航与现场；白色内容块承担实际任务分区，不为每个数字另造卡片。任务操作栏用蓝色边线识别，状态色只表达状态。长恢复说明按需展开，但“先核对动作结果”等真实标题可见。列表使用最大高度而非固定空高度；短列表不留一大块空白。

## 操作与回溯契约

1. 示例仅写入草稿；生成、审批、暂停、继续、取消沿用原服务端准入。打开历史、搜索、复制和进入诊断不能调用物理动作。
2. 使用准备采用原 readiness 判定，折叠不修改准备状态、现场确认或标定结果。缺失/未知不显示为就绪。
3. 搜索在已加载历史缓存中进行，大小写与首尾空格归一，和状态过滤共同生效。搜索覆盖列表显示窗口之外的已加载记录；记录已清理时不能通过搜索恢复。
4. Local 记录页打开任务后保持该页和关键词；后续同任务的 experience 持续更新。任务编号 lookup 仍能读取列表窗口之外的持久任务。
5. 回放提供复制编号和进入诊断；诊断保留选中任务。operator edition 不展示诊断入口。界面模式不是权限边界。
6. 复制受限时给出手动复制提示；排查摘要复制失败时展开原摘要。摘要继续使用字段白名单，排除任务原文、凭据及原始遥测。
7. 全部事件折叠不截断数据、不改变证据校验；生命周期和原图入口保持原关联。
8. 记录页状态只表示记录 API 的读取结果，不把停止刷新的直播相机当成记录断线，也不宣告机器人可安全移动。
9. 桌面记录与回放并排，窄屏列表在前；有界列表可聚焦并用键盘滚动。保留 focus-visible、跳转主要内容、原生 details 和 reduced-motion。
10. 相机不可用显示未知与连接入口，不生成替代场景或假实时画面。

## 验收

- 行为测试：跨显示窗口搜索、组合状态过滤、搜索不发网络请求；打开记录留在原页且不审批；诊断上下文和复制反馈切换；未知现场与历史可读状态区分。
- 回归：全部 Web tests、嵌入资源与 Console Go tests、build/lint/generate-check；合入遵循 release-gate。
- 浏览器：实际服务数据，键盘示例、编号 lookup、成功/失败回放、复制、诊断、准备/事件展开。检查 1280px、默认平板窗口和 390px 的顺序与溢出。
- 更新用户说明、前端说明、docs/book 增量入口。书籍 1.0.0 正文保持冻结身份。

限制：本轮不构成新一轮运动闭环或实机认证，不修改 Fleet 的“创建并开始”行为，不改服务端安全权限，不把历史任务列表当成跨机器人检索平台。
