# 产物治理、当前文档与书籍 2.1.0 更新计划

日期：2026-10-14。基线：`56c16c485efa2bd8037ab75bcb6be2d3643c3f5a`。目标是清理明确可再生成的临时产物、让当前操作指南与 ROS 2 空间升级一致，并发布面向教学与工程的书籍 2.1.0。

## 范围与实施顺序

1. 核对 artifacts 的大小、Git 跟踪、文档引用与打开文件。保留实验原始数据、失败、地图、标定、任务库、Runtime journal 和历史出版包；只清理未引用的 scratch 临时文件及被 bin/ 取代的旧根目录 CLI。
2. 更新模块边界、SLAM Provider、异构接入、部署、研究与学习导航；发现的过时能力表按当前代码修正，带日期的历史报告继续保持原结论。
3. 保存 2.0.0 的固定 Git 恢复清单与逐文件 SHA。2.1.0 保持四篇、19 章和 9 附录，补齐语义点云、持久合同固定、设备数据交换、SE3 注册测量、地形/体素导航与最新实验；增加可运行的软件实验。
4. 修复出版器允许不同身份内容覆盖已有版本目录的问题。相同来源/工具/依赖可重复构建，不同来源必须使用新版本或新目录；测试拒绝路径且核对旧字节未改。
5. 运行文档、书籍、回归与电子出版检查，记录结果和新出版包 SHA。提交并推送；先合入已有基础 PR，再将升级 PR 合入 main，保留提交历史和快照身份。
