# SLAM 三维点云语义层实施计划

日期：2026-10-13。基础提交：`fd77437664d33c81b0c1479222120322240f47e2`。

## 问题与目标

现有 SLAM 输出测量点云、导航栅格、关键帧、命名工作区和物体记忆；工作区名称主要来自部署配置。缺少对已保存点云中的任意区域或物体进行版本化标注、检索和空间关联的接口。目标是把几何地图扩展为 Agent 能按需查询的三维语义地图，而不把全部点云送进模型上下文。

本轮采用人工标注优先的开放语义层：在地图坐标系内使用三维包围盒选中实际点云点，记录标签、类别、别名、来源、置信度、观测时间，计算点数、实测边界、质心及选择摘要。接口允许感知提供者提交同一契约，但本轮不声称已完成开放词汇视觉分割、自动理解全图或真机验证。

## 实施与验收顺序

1. 审计当前 SLAM、地图包、服务发现、导航及 Console；保留现有测量与运动准入。
2. 实现独立语义存储：绑定 robotId、mapId、mapRevision、calibrationRevision、cloudSha256、frameId；追加版本历史，CAS 阻止云边或多操作员覆盖；历史地图标签不能静默迁移到新图。
3. 实现实际点云选择、范围与输入预算、包含关系、同类重叠冲突和新鲜度；缺少点、错误坐标、歧义、过期均明确报告。
4. 注册 semantic.map/query/annotate/history/plan 服务；规划模型只能在审批前调用 READ 服务及其有界语义投影。标注是版本化配置写入，不产生物理运动。
5. Console 提供可操作的标注与查看入口。规划服务提出当前足迹、已知栅格和连通路径支持的观察候选；候选不是抓取姿态或运动授权。
6. 单元与跨模块回归覆盖并发、持久化、篡改、地图变化、未知栅格、断连通路、模型上下文边界；用上一轮真实 Gazebo 采集的地图开展可复现回放实验，单独标记合成测试与仿真实测点云回放，保存输入、版本、原始输出与失败案例。
7. 记录测试结果、使用方式、限制及下一阶段工作，提交并推送功能分支。

## 坐标与冲突原则

- 地图包保持不可变。语义 revision 独立于几何 revision，不建立循环哈希。
- 包围盒只是人或感知提供者的标签声明；点数证明几何支持，不证明类别正确或物体仍在原处。
- 允许区域包含物体；重叠物体或重叠区域显式报告，不按置信度悄悄覆盖。
- 地图优化、续建或标定变化后必须重新绑定并复核标注；本轮不自动搬运旧坐标。
- 历史点云、几何质心和标注不替代实时定位、障碍检测、物体重识别、机械臂 IK 或抓放验证。

## 技术依据

RTAB-Map 提供 RGB-D/激光几何建图及点云输出；语义层建立在这些测量之上。参见 [RTAB-Map 官方仓库](https://github.com/introlab/rtabmap_ros)。本轮使用现有 NumPy 点云与空间范围选择，无需新增大型推理依赖；三维包围盒与点云裁剪的通用操作参见 [Open3D 官方文档](https://www.open3d.org/docs/release/tutorial/geometry/pointcloud.html)。
