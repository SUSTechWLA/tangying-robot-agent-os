# 2026-10-21 · 教材 3.0.0：架构推导、源码与故障实验

本次按用户反馈重编书籍：原书过多采用功能/审计清单，缺少可推演的例子与设计理由。目标读者是具备编程基础的本科生、研究生及系统开发者。验收对象是教学材料与出版产物，不是新的机器人软件版本或硬件上线结论。

## 1. 编辑计划与取舍

1. 保留四篇、19 章、9 附录和 57 道分层题，使旧学习路径仍可定位；重写全部正文，集中讲授第 2、3、5、7、8、17、18 章。
2. 以 AGV 的 A→B→C→A 巡检贯穿，增加 UAV 观察建议。每章从问题出发，解释设计、数据流、失败反例、实现与代价。
3. 将长串历史身份和来源目录留在附录与原报告；正文保留能够解释机制的实际成功、失败和人工介入。
4. 增加 16 幅离线 SVG、两个标准库小实验、两组项目实验和课堂脚本，使抽象机制能够预测、运行、对照。
5. 核对代码快照与测试，构建离线 HTML/EPUB；归档旧版，更新入口文档并提交。

正文更短不表示删掉故障边界：主要删去重复限制、版本清单和泛化总结，将篇幅用于具体决定。不存在“所有章节平均讲一遍”才能学懂的要求。保留研究题，但本科主线只要求能解释和验证关键反例。

## 3. 图与出版器

`scripts/build_book_figures.py` 用标准库确定性生成 SVG；图表有 title/desc，架构与顺序、分类与条件分支分别表达。编辑检查发现恢复/异构/上下文用串联框容易误导，改成分支图与双路径图；peer 消费末端改成本地处理，避免画成对发送者的执行指令。文字标注加背景描边，避免穿线。

`scripts/build_book.py` 新增本地被动 SVG 校验、资源复制与 EPUB manifest 打包。拒绝远端图、缺失路径、脚本/样式等活动资源和输出符号链接；图像 SHA 纳入 provenance 与校验清单。`make book-check` 与 `make book-release` 先检查图表是否与生成器一致。同版本内容变化仍拒绝覆盖已有发布目录。

本版代码与配套文档固定到 `9e6a58f6ad48c6d9441e95511ddb4d503ea6449e`；书稿版本为 3.0.0。`book/editions/2.2.0/` 保存旧版身份、31 源文件、合订本、README、生成器和依赖哈希。归档回归从 Git 逐项比对，不能以新文字覆盖旧实验身份。
