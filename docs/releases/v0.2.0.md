# 躺营 v0.2.0

> 2026-09-09。标签、最终提交、逐项 CI 结果和制品校验值见本版 [GitHub Release](https://github.com/SUSTechWLA/tangying-robot-agent-os/releases/tag/v0.2.0) 的 `release-manifest.json`。

本版以单机器人完成一个限定工位的自然语言任务为交付主线：从离桌初始位置观测环境，分解任务，通过双 RGB-D、RTAB-Map 和 Nav2 接近工作区，抓取、放置，并以动作后原始观测确认结果。多机器人与异构机器人接口继续保留；当前实机仍须逐台完成驱动、标定、策略、地图及现场验收。

软件正式版本与实机放行是两项独立结论。`v0.2.0` 不代表已经完成真实 XLeRobot 的无人值守生产验收，也不替代现场 `PHYSICAL_GO`。

## 获取准确版本

使用正式标签获取本版，避免跟随尚未验收的开发提交：

```bash
git clone --branch v0.2.0 https://github.com/SUSTechWLA/tangying-robot-agent-os.git
cd tangying-robot-agent-os
make setup
make build
./bin/robot-agent version
```

`VERSION`、Python 项目、内置 Runtime 与 ROS 包均为 `0.2.0`。`make build` 和角色安装器将 `v0.2.0` 写入 CLI；安装回执另外记录提交。`--version` 只覆盖安装标识，不会切换仓库，部署前必须检出正确标签。协议、MCP 和机器人 profile 的独立版本不随软件版本改动。

核心依赖基线为 MuJoCo `3.11.0`、NumPy `2.4.6`、gRPC Runtime `1.83.0`、代码生成工具 `1.81.0`、Protobuf `6.33.5`、Pydantic `2.13.4`（对应 core `2.46.4`），由 `pyproject.toml` 固定。Protobuf 6 同时满足 LeRobot 的依赖要求；重新生成的存根保留相同的序列化协议描述。Robot Edge 使用 `.[robot-pi]` 安装固定的 LeRobot／Feetech 与 OpenCV 组合，执行依赖一致性检查。完整边界及独立 MuJoCo 3.12 兼容检查见[依赖与兼容说明](../development/mujoco-compatibility.md)。可选依赖与 RoboCasa 环境不据此视为全部锁定。

## 本版范围

- 单机器人、限定物体和工位的自然语言任务闭环；移动入口从操作位后方 65 cm 起步，本轮实际接近约 64.2 cm。
- 机载头部与底盘 RGB-D、规范三维观测、彩色点云；用户画面与任务证据使用机器人观测数据。
- 可选 RTAB-Map 建图／保存地图定位与 Nav2 导航；到达目标后重新观测，定位或输入过期时停止。
- 原始观测回看、任务与工具记录、工具边界暂停与恢复；未知物理结果禁止盲目重放。
- 统一工具和 MCP 接入、机器人能力 profile 及适配器边界，便于后续接入 ROS 和其他型号。
- 明亮中文工作台、用户／开发模式、固定画面尺寸及独立刷新。

本发布线基于 `codex/v0.1-production-upgrade` 继续开发。原默认 `codex/v0.1` 有另一条多机器人同步 RGB-D 与可重复 RoboCasa episode 工作线；其独有提交保留，不能据此声称已全部包含在本版。后续合并需单独核对协议、任务持久化、场景 reset 与历史签名证据。

## 升级与回滚

升级前停止新派发并备份持久任务、证据、地图和 Runtime journal；在无持物等安全状态切换软件版本。重新核对设备身份、相机／地图／标定版本，并在本地验证后恢复操作。软件回滚不能删除 journal、重放结果未知的动作，或降低 task revision、fencing token。详见[部署与容量](../production/deployment-and-capacity.md)。

导航 journal 迁移增加完成来源与完成决策所依据的定位时间。历史记录继续保留；缺少这些字段的旧成功记录不能补造成当前导航成功回执。`pose_confirmation` 仍需新鲜定位及独立里程计通过同一到位门槛，不授权未经收臂验证的非零速度。

实机接入流程见[购机后 Sim2Real 上手](../sim2real/README.md)，导航流程见[RTAB-Map / Nav2](../development/rtabmap-navigation.md)。现场负责人需要另外核对真实串口、电机、实体急停、感知质量、操作范围与长期可靠性。
