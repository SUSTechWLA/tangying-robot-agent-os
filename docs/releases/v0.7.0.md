# 躺营 v0.7.0

2026-09-21。v0.7.0 的正式发布由 `main` 上的同名附注标签固定；候选分支本身不构成发布，标签只能在发布门禁通过后创建。相对 v0.6.0，新增物理接地验证、结构化 Agent 上下文和系统级评测底座，并整合 Gazebo、建图/标定与监督恢复的核心实现。

## 获取与使用

```bash
git clone --branch v0.7.0 https://github.com/SUSTechWLA/tangying-robot-agent-os.git
cd tangying-robot-agent-os
make setup
make test-agent-system
make home-furnished
```

家庭仿真操作见 [装修家庭演示](../guides/furnished-home-demo.md)，Gazebo 入口见 [家庭仿真操作](../guides/gazebo-house-operations.md)。完整软件版本、Python 包、机器人运行时与 ROS 包统一为 `0.7.0`；线协议和既有 `*.v1` 数据契约保持各自版本。

## 核心变化

- **机器人运行链**：Gazebo RGB-D 与位姿桥接、注册服务、建图工作流、接触实验后端及机械臂参数生成。MuJoCo 和 Gazebo 复用相同机器人/服务边界；各后端的已实现能力按实际目录声明。
- **建图与标定**：自然语言建图请求、地图库存与选择、语义工作区、探索前沿与覆盖评测、导航后的作业条件判断、手眼/几何标定求解与可视化引导。
- **物理接地验证**：Grounded Contract Language、独立验证器、VERIFIED/FALSIFIED/UNKNOWN、证据引用和分类恢复建议。工具 SUCCESS 不替代物理证据。`TANGYING_GVF_ENABLED=1` 显式开启可选验证路径，默认关闭。
- **Agent 上下文**：版本化事实包、来源/时序/作用域约束、确定性 JSON/自然语言渲染与分阶段表达实验。`TANGYING_AGENT_CONTEXT` 默认 `legacy`；研究配置的模型/阶段适用性限制继续保留，不能用某阶段的准确率替代完整任务成功。
- **系统 Eval**：20 项能力、7 层评测、12 类公开工具、34 个基础指标，以及严格配对比较、缺测/不适用处理、簇级统计与三态研究门禁。见 [设计与使用](../architecture/agent-evaluation-system.md)。本版提供离线评测底座，尚未统一接入所有闭环和实机 runner。
- **监督与恢复**：包含 v0.6.0 之后主线上已合入的多 Agent 运行时、运维诊断、审批范围、恢复执行与复验、任务回放、问题聚合及控制台轮询修复。恢复不会绕过权限或将未知物理结果当作成功。

## 仓库与实验数据

- 代码、schema、配置、回归测试、复现实验脚本、结论性报告与少量最终图表进入 Git。
- 原始模型响应、传感器帧、地图、临时 benchmark、缓存、日志、回滚副本和本地发布检查目录不进入本次提交；已有历史提交不重写。
- `make test-agent-system` 使用独立测试样本，可在新检出运行。`make eval-agent-system-demo` 需要另行准备本地历史实验归档；报告中本地证据路径明确标记，不假定克隆仓库就附带这些数据。
- CHANGELOG 收敛为版本摘要，完整实验方法和结论集中在 [实验报告索引](../experiments/README.md)。旧开发报告入口保留跳转，兼容已有链接。

## 发布验证

发布前须通过 `make build`、`make lint`、`make generate-check`、`make test` 与文档检查，并在不含本地实验目录的独立检出中验证。各平台 CI 结果关联实际提交，`release-gate` 汇总软件测试、安装计划、ARM 依赖、ROS 构建和 MuJoCo 兼容性；任何失败、取消或跳过均阻止合并。最终提交的检查记录随 GitHub Release 提供，历史实验指标不作为当前版本验收结果。

## 已知边界与升级

- 本版是有明确适用边界的软件版本，不是实机安全认证。新机器人、场景、标定和地图仍须按 [发布验收清单](../operations/release-checklist.md)完成对应现场测试。
- 历史实验存在规划、恢复和部分验证器判定的未通过结果；这些结果完整保留在报告中，不能因为代码发布而改称能力已通过。
- 系统 Eval 的示例门禁只覆盖一个主指标和一个风险指标，不代替完整发布/实机放行。历史回放也不证明新候选的物理闭环收益。
- 新增研究模块按需开启，保持已有默认路径。升级前备份任务数据库、机器人配置与标定；场景几何或标定变化后重新校验地图身份。回退使用上一稳定标签 v0.6.0，并先核对数据兼容性，不重放未知物理命令。
