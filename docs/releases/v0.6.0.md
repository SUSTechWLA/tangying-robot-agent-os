# 躺营 v0.6.0

2026-09-13。此版本发布于 `main`，以附注标签 `v0.6.0` 固定代码身份。

本版交付装修家庭场景、注册服务标定与移动建图、保存地图的彩色点云和关键帧诊断，以及基于当前 RGB-D 证据的自然语言移动抓放流程。Robot Agent OS 通过注册服务运行，环境实现保留在驱动内部。

## 获取与启动

```bash
git clone --branch v0.6.0 https://github.com/SUSTechWLA/tangying-robot-agent-os.git
cd tangying-robot-agent-os
make setup
make home-furnished
```

打开 `http://127.0.0.1:8897`，依次完成整机标定、巡检建图、地图启用，再提交任务。详细步骤见[装修家庭演示](../guides/furnished-home-demo.md)。

`VERSION`、Python 项目、MuJoCo/适配器运行时与 ROS 包统一为 `0.6.0`。线协议 `1.0` 和现有 `*.v1` 数据契约不随软件版本号变化。

## 本版变化

- 暖木地板、厨房与卫浴瓷砖、MIT-0 家具资源及生活陈设；可操作物为陶瓷杯与收纳盘，旧颜色工位保留为兼容基线。资产固定源版本并记录哈希，可通过脚本重建。
- 标定页支持注册算法与用户自行录入。机器人移动采集 RGB-D，生成不可变地图、导航栅格和显示点云；活动地图与场景、标定版本校验绑定。
- 点云支持实测 RGB、辅助色、房间聚焦、本机标记；关键帧详情提供同帧图像预览、原始/优化位姿、配准和回环质量，严格区分缺失历史信息。
- 自然语言解析完整覆盖支持的子句，将抓放绑定到正确房间访问；语义服务发布实际配置的可操作物品目录。
- 导航采用连续路径间距校验；本地派发使用注册能力预算，驱动响应连接取消、租约和截止时间。托盘依据当前可见连续边段识别，不通过历史位置缓存推断放置成功。

## 升级与边界

- 旧任务记录继续保留。旧地图只能展示其实际保存的信息，没有预览时不会调用实时相机补齐；没有改变场景与标定的地图仍可经过身份校验后启用。
- 家具几何、材质或标定变化后需要重建地图；不要把旧世界地图直接用于新世界导航。每次搬运测试使用尚未放置杯子的初始物品状态，显式重启前先结束或停止任务。
- 本版完成的是受限家庭仿真软件验收。几何识别、平面 SLAM 和保守碰撞模型有明确范围，不代表已训练通用家庭策略、任意机器人免适配或实机现场放行。
- ROS 原生构建与 Linux 平台覆盖由仓库 CI 执行；本机 macOS 结果不冒充这些平台的验证。
