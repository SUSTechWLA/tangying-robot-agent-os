# 三维点云语义层：历史 Gazebo 地图回放与工程验证

日期：2026-10-13。基础提交 `fd77437664d33c81b0c1479222120322240f47e2`；实际被测源码字节保存在证据包中。实现及使用见[点云语义指南](../guides/semantic-point-cloud.md)，过程计划见[开发记录](../development/2026-10-13-semantic-cloud-plan.md)。机器可读数据：[JSON](2026-10-13-semantic-point-cloud.json)、[逐案例 CSV](2026-10-13-semantic-point-cloud.csv)。

## 研究问题与范围

研究问题：在不改写几何地图的情况下，系统能否把已测点云中的物体/区域声明持久化，按名称和空间包含关系检索，识别过期与版本冲突，并在小型 Agent 上下文中提供具有坐标身份的观察候选？

本轮实现前，系统已有点云、测量栅格、配置命名的导航地点和物体记忆；浏览器任意点标记主要保存在 localStorage，不能作为 Runtime 的版本化点集合语义供 Agent 查询。新增层通过相同地图/点云身份、独立语义版本、CAS 与服务目录接通这些能力。这是功能扩展和契约验证，**没有测量 SLAM 定位精度、自动识别准确率或机器人长程任务成功率的提升**。

本轮没有启动新的 Gazebo 运动任务，没有使用真实硬件，没有调用视觉识别模型。分别记录：合成单元测试、真实历史 Gazebo 点云离线服务回放、模拟服务的浏览器冒烟。不能将它们合并成机器人任务成功率。

## 上下文、回溯与独立复核

原点云1,079,720字节；9份规划投影的 Python 保守字节测量最大1,964字节。独立使用生产 Go `validatePlanningView` 与 `encoding/json.Marshal` 检查这9份真实投影，全部通过，实际序列化范围385–1,845字节，最大嵌套深度5，低于8KiB/深度8上限。不同序列化的转义和空格导致两种数字不同。

这是“选择哪些结构化信息送入规划器”的负载测量，不是无损点云压缩率、输入 token 数、推理费用或任务性能收益。语义查询按实际字节预算缩页并返回 nextOffset，不能假设 offset 每次增加请求的 limit。

回放本身153个文件、9,569,467字节全部 SHA 复核。初始证据包加上测试、UI和审查记录后，包含176个带摘要的数据文件，共11,065,790字节；tar.gz为5,853,399字节，SHA-256：

`bc80b380a085a85a158a008b6a4ebcafc8f12fd5ab00f922326b8202382accf0`

本地路径：`artifacts/experiments/semantic-cloud-20261013-evidence.tar.gz`。原始证据包未上传远端，Git 保存实现、测试、报告与小型索引。包内 `evidence-manifest.json` 与 replay manifest 支持逐文件复核；包内源码快照是对应回放的被测版本。

最终独立复核发现并修正了下述前端来源/置信度问题，原包保持不变。补充包 `artifacts/experiments/semantic-cloud-20261013-final-review-evidence.tar.gz` 保存修正记录、补丁、最终前端源码、516项Web测试日志、Go Web race输出、重新构建摘要和补充浏览器实验；13个数据文件，压缩后349,896字节，SHA-256为 `0631c8bf5e326c875867478cfcb24fdbc35f94ae43573c9978e34d0b4d0c26f5`。补充浏览器采用模拟感知记录，验证仅改名仍保持来源类型、0.2置信度、原引用与时间。没有重新运行未变更的Python点云回放，也不把浏览器重跑算作新的机器人任务。

SQLite 追加与 SHA 链不能防止数据库管理员删尾部或恢复旧备份。实验把 head 和文件 manifest 另行归档，避免将本地内容校验夸大为可信防回滚系统。Go 投影审查记录注明：执行输出事后留档，文件哈希在留档时读取，不声称执行时原子取证。

过程修正保留如下，不能计为额外成功机器人实验：

- 独立代码审查发现长时间点云计算持有停止/租约锁，改成短快照、锁外计算和身份复核，并有并发测试。
- 修正只按记录数控制查询大小、异构大底盘候选超距离、校验后重新读点云的竞态、缺坐标版本/定位时间投影、空语义误报零点云，以及提交后切图错误报告“无副作用拒绝”。

- 最终复核发现编辑感知标注时硬编码 `operator / confidence=1`，会丢失原来源并绕过低置信度检查。修正为从完整快照保留来源类型与置信度，新建才使用人工默认值；增加两项Panel回归和真实浏览器的模拟感知记录改名验证。补充Go Web race检查与Local Agent构建均通过。

- 上一轮 PR25 的远程 CI 唯一 Python 失败为新脚本 `evaluate_goal_rejection.py` 未加入会话认证分类。实际请求通过 EvidenceAPI 已带会话；本轮补显式委托链分类和创建/取消 POST 请求头测试。原远程 PR25 未被本轮修改或重跑。

## 结论与下一阶段

证据支持：版本化点云标注可以成为可查询的机器人侧语义数据，多客户端冲突能显式拒绝，历史与几何身份可回溯，Agent 可读取小型摘要而无需整份点云。观察候选保持现有几何准入与不授权执行的边界。

尚未证明：开放词汇自动识别、分割掩膜投影精度、跨回环重融合、动态物体跟踪、跨机器人地图对齐、多楼层导航、网络分区下副本同步、真实硬件任务、任意新标签直接驱动导航抓取。下一阶段应围绕这些能力定义新的配对实验、独立人工标注真值和物理完成判据；不能根据本轮12项回放把全系统标记为“已理解整个地图”。
