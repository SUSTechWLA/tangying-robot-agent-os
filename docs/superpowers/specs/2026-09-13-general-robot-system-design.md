# 通用移动操作 Agent 系统升级

用户目标：自然语言驱动底盘与机械臂，涵盖首次标定、SLAM、地图管理、语义导航和家庭仿真，降低使用门槛。

## 已核对的边界

保留 Go Agent/taskgraph/closedloop、Python Robot Runtime、安全监督、ROS 2 RTAB-Map/Nav2 和 Three.js。主交付是本地单机器人，Fleet 是可选控制面。任意机器人意味着经配置和验收的 RobotProfile/adapter 接入，不能承诺未知硬件免标定可运行。

## 实施顺序

1. 工具执行必须通过同一个 RobotRuntimeService（安全、租约、幂等、取消、急停），禁止直接调用 PluginBackend。工具参数在执行入口验证。超时工作线程退出前保留执行资源；急停可抢占，读操作可观察。未知结果不可自动重试。
2. 地图分三种产物：SLAM 数据库及测量点云、Nav2 占据地图、用户观看的分层点云。展示图像不得当作导航栅格。导出使用标准 PGM/YAML，保留 unknown/free/occupied。优先导入 SLAM 权威栅格；点云投影必须记录地面/高度限制、坐标系和标定版本。
3. 语义工作区属于具体地图版本，包含名称/别名、候选底盘位姿、机械臂可达性约束。候选必须在已知空闲区域满足底盘足迹及目标距离/朝向；IK、碰撞和到达后重新感知由机器人适配器完成。显示选择不等于运行时地图切换。
4. 自然语言解析增加导航工具入口，保持完整意图校验与未知参数拒绝；LLM 不提供任意坐标或安全字段。固定家庭场景坐标只在明确的仿真适配器中使用，其他机器人从观测/配置解析语义目标。
5. 下载家庭仿真资源时固定上游版本、验证文件并保留许可。仿真资产不冒充用户家中的实测 SLAM 地图。保留当前 MuJoCo 回归场景。

## 验收

每个修复先增加行为回归测试。运行 Go/Python/Web 的相关测试及整体检查。执行至少一条隔离家庭仿真自然语言任务，保留工具与观测证据。不能在本机验证的 ROS/硬件/真实 LLM 项明确标记，不能从单测推断实机通过。
