# 单机器人 RGB-D 闭环实施计划

**Goal:** 在单机工作台验证自然语言到相机感知、控制、反馈、恢复与追溯的完整链路。

**Architecture:** 共用机器人与重建契约，单独提供无世界真值回退的 RGB-D 路线；Local 持久化恢复和 ROS 输入并行完成。
