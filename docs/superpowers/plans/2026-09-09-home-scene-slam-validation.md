# 家庭场景 SLAM 与自然语言任务验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** 新增一个包含客厅、卧室、卫生间、厨房和连通走廊的 MuJoCo 家庭场景，使用 XLeRobot 的 RGB-D 观测接入现有 RTAB-Map/导航链路，并用可恢复、可回溯的自然语言任务完成一次“观察家庭环境 → 建图/定位 → 跨房间导航 → 到达确认”的生产前验收。

**Architecture:** 家庭场景作为独立 `scene=home` 配置加载，沿用真实 XLeRobot 资产、头部 RGB-D 与底盘 RGB-D 相机，不注入仿真真值地图。家庭场景提供可见纹理、墙体、门洞和语义房间标记，导航控制按短路段增量执行；RTAB-Map 仍是外部地图/定位来源，仿真只负责发布传感器和执行受限底盘动作。现有 tabletop 默认行为、任务模型和回归测试不改。

**Tech Stack:** MuJoCo XML/MjSpec, Python 3, existing RGB-D runtime, RTAB-Map/Nav2 ROS 2 bridge, Go deterministic intent parser/task service, pytest/go test, shell acceptance scripts.
